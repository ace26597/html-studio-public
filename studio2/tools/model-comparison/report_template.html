    How this was run

    • Every model got the same brief and the same 453-row data file, in a new project in one studio, through one route: Claude Code as the agent, a LiteLLM gateway, OpenRouter. Claude Fable, Opus and Sonnet ran on a Claude plan; Sonnet and Haiku also ran through OpenRouter.
    • The data is generated sample data with a fixed seed, so the right answers are known: .
    • One request per model. That shows what a model did this once; it does not show how often it would do it again. A model that failed here may pass on a retry, and the reverse.
    • The eleven checks are mechanical. How good a page looks is not one of them; a comment on looks is one reading of the pictures and is marked as that.
    • Cost is what the gateway recorded for the request. A run stopped at the 15-minute limit is counted as not finished.
